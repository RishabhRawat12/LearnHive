# LearnHive Frontend

This is the frontend for LearnHive, a peer-to-peer tutoring platform.

Built with React, TypeScript, and Vite, and styled with Tailwind CSS and shadcn/ui.

## Tech Stack

* **Framework:** React
* **Language:** TypeScript
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **UI Components:** shadcn/ui
* **Routing:** React Router
* **State Management:** React Query
